Global Deterministic 10km Forecast

At a glance Samples Usage examples API Docs Support

Overview

A numerical weather prediction forecast for the whole globe, with a resolution of approximately 0.09 degrees i.e. 10km (2,560 x 1,920 grid points).

The global deterministic model is a global configuration of the Unified Model, which is the Met Office's flagship Numerical Weather Prediction model. The model's initial state is kept close to the real atmosphere using hybrid 4D-Var data assimilation.

At a glance

Domain:
Global (region can be selected)
Product type:
Forecast
Resolution:
10km (2,560 x 1,920 grid points)
Projection:
Equirectangular Latitude-Longitude
Parameters:
144 available across multiple levels
Time steps:
Every hour 0 to 54 hours, every 3 hours between 57 & 144 hours, every 6 hours between 150 & 168 hours
Forecast length:
7 days (168 hours)
Update frequency:
4 times daily (for the next 168 hours at 00:00 & 12:00 UTC, for the next 66 hours at 06:00 & 18:00 UTC)
Delivery method:
API
File format:
GRIB2 - Gridded Binary Format
